# Root — tema Kando

Centro de mando hacker: verde fósforo sobre negro, línea de escaneo.

Derivado de Alpha Neon (CC-BY-4.0, por digitalart3d y Elfi Ox).

## Presets de color

- **Root**: los colores de firma de este tema.
- **Matugen**: sigue al fondo de pantalla (lo genera `kando-matugen-sync.py` en cada cambio de fondo; no editar a mano).

## Instalar

Copiar esta carpeta a `~/.config/kando/menu-themes/` y elegir el tema en Kando → Ajustes → Appearance → Menu Themes. Reiniciar Kando si no aparece.
